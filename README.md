# Mansyd Website

## Run locally

1. Install Node.js 22 or later.
2. Start the backend first, following the backend repository's README.
3. Open a separate terminal in this folder and run:

```powershell
npm ci
npm start
```

Open http://localhost:4200. Keep both the backend and frontend terminals open.
